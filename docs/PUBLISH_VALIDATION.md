# 验证范围与示例结果

## 离线测试

项目包含52项离线测试，覆盖正交投影、旋转矩阵、单位转换、裁剪、RGB保留、PNG与SVG映射、照片模板、自动轮廓、零件拆分及防覆盖。采集测试使用模拟设备验证资源释放，不代表实体相机已在每台电脑验收。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

[GitHub Actions](https://github.com/lilili-maker/3dsvg-studio/actions)在Windows / Python 3.14环境安装依赖、执行测试，并运行附带真实示例的自动轮廓提取和编号拆分。2026-10-16的工作流已通过；后续提交以Actions中对应提交的状态为准。

## 真实示例

- 输入是examples/chair/capture中的同一组RGB-D，640×480像素，Depth为原始uint16。
- prepare入口生成点云、正交参考PNG/SVG和照片描边底稿，输入文件保持不变。
- 示例ROI为185 15 495 480，默认深度范围0.2～3米时，自动提取11条候选轮廓：10条闭合、1条开放。
- 已查看自动预览：座面下方存在地面误分，细金属腿和轮子存在缺漏，不能视为完成的零件线框。
- 附带final.svg为另外完成并校对的照片透视线稿；两处轮子轮廓含已标记的人工估计补线。
- 使用附带parts_config.json拆分该线稿，生成001.svg～011.svg，并验证了实际Path、变换、颜色与编号映射。

## 同一线稿的两个版本

[椅子示例](../examples/chair/README.md)同时提供细节版与精简版：细节版包含43条路径，精简版保留26条结构路径，删除17条细节线，并将保留线条统一为2 px。保留路径的`d`坐标、图层变换、颜色及两处轮子人工估计标记已逐项核对。

两个版本各包含11份编号零件SVG，已检查路径归属、无重复分配、没有未分配路径，以及拆分报告中的SHA-256与实际文件一致。原版整图与原始RGB-D未改动；两个PNG预览均为760×1070像素。

## 检查方法

检查SVG中的实际Path及其坐标、嵌入PNG和画布映射，不只判断文件是否存在。孔洞和多轮廓通过实际分割测试验证；检测到的ROI/画面截断边界保持开放。源图通过SHA-256校验，原始Depth不会被改写。

## 验证边界

自动分割和AI描边均需人工检查。照片透视线长没有实物毫米标定，合成几何测试不能证明实际D435i测量精度。Inkscape中的人工编辑和物体可见性需结合本次照片确认。
