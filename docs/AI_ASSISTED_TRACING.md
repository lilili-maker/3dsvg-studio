# 用AI辅助SVG描边

AI是可选的绘图辅助，不是精密测量工具。当前脚本不绑定任何AI服务、机器人或API；你可以在自己选择的工具中上传本次RGB图及对应的SVG底稿。

## 先准备什么

1. 一张轮廓清楚、整件物体入框的真实RGB照片。
2. 本次生成的 `photo/edit.svg`（照片路线），或 `pointcloud_template/template.svg`及reference.png（正交投影路线）。
3. 如有真实尺寸，单独给出卷尺测量值；没有就不填。

也可以先运行 `run_workflow.py auto-contours`，把其 `editable.svg` 和原RGB交给AI修正候选轮廓、补可见内部线、按零件分组。自动轮廓可能混入地面或漏掉细腿；请明确要求删除错误背景线，不把候选路径直接当作正确结构。完成后在final.svg副本中移除剩余auto_contours候选层，再执行split；该独立底稿不使用照片项目的export命令。

**不要混用不同路线的坐标。** AI从RGB照片描出的曲线保留透视，不可当作另一张点云正交参考图的同位轮廓。新照片不能直接套用示例椅子的路径。

## 照片路线：可复制提示词

```text
请根据附件真实RGB照片和对应SVG底稿，辅助制作一张可在Inkscape编辑的彩色线稿。

要求：
1. 以SVG底稿里的照片位置为准，保留根width、height、viewBox、来源元数据、Reference图层及照片映射。
2. 只在对应部件图层画真正的SVG Path，填充none，使用内联彩色stroke；保留开放曲线，不使用图片截图代替线稿。
3. 根据本物体实际结构划分部件；没有扶手等部件就留空。每个独立零件使用一个有唯一ID的group，轮子分别分组，便于后续拆成独立文件。
4. 保持照片透视，不宣称真实等轴测、三维恢复或毫米标定。
5. 只描可见结构。遮挡或出画部分留空；若我明确要求补画，新增部分单独标记data-geometry-source="manual_estimate"并说明。
6. 不添加猜测尺寸；真实尺寸只能使用我提供的实测值。
7. 保留可编辑的贝塞尔曲线、原图层ID及合法变换，不添加脚本、外部资源、滤镜或复杂路径效果。
8. 返回完整SVG文件，而不是仅给截图或无法复现的描述；逐项说明哪些地方有不确定性。

我会在Inkscape中人工校对，确认后再隐藏Reference和Guides，另存干净的final.svg。
```

## 正交点云路线的额外要求

把上面“照片”替换成对应reference.png。要求AI沿底稿现有投影画线，不根据另一张透视照片改变轮廓位置，不调整projection.json描述的映射。点云缺口不是实测的实体边缘；不确定处应留空或明确标记人工估计。

## 人工必须检查

- Inkscape能正常打开，隐藏Reference后仍有真正的可编辑路径。
- 靠背、坐垫、底座及每个轮子的线条属于正确部件；不把实验室背景一起画入。
- 原页面尺寸、投影版本及底图位置没有改变。
- 没有把透视线长当作真实尺寸，没有凭空出现未拍到的背面结构。
- 确实需要闭合的轮廓才闭合；人工补轮等新增线有估计标记。
- 曲线和颜色在浏览器、Inkscape中一致；没有外部图片链接或脚本。

若采用照片进度工具，可在保存 `edit.svg` 后运行 `run_photo_svg_workflow.py export --project 项目目录 --reviewed`。这会检查格式、来源绑定和路径，但不能代替你判断画得是否正确。

最终用 `split_svg_parts.py` 或 `run_workflow.py split` 按分组拆分。没有适当分组时，先在Inkscape里选择同一零件的线条，Ctrl+G并赋予唯一ID。零件文件只叫001.svg、002.svg……；名称映射保留在报告中。
